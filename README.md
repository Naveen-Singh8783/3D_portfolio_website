# 🚀 3D Developer Portfolio

A modern, interactive **3D developer portfolio** built with React, Three.js, and TailwindCSS to showcase projects, skills, and experience in an engaging way.  
The portfolio is live here: **[🌐 Visit My Portfolio](https://naveen-singh-portfolio.onrender.com/)**

---

## 📌 Features
- 🎨 **Modern UI/UX** with smooth animations and responsive design
- 🖼 **3D Models & Graphics** powered by `Three.js` and `react-three-fiber`
- 📱 Fully responsive for desktop and mobile
- 📂 Sections for **About**, **Experience**, **Skills**, **Projects**, and **Contact**
- 📨 Integrated email contact form with `EmailJS`
- ⚡ Optimized performance with lazy loading and asset compression

---

## 🛠 Tech Stack
- **Frontend:** React, TailwindCSS
- **3D Rendering:** Three.js, React Three Fiber, Drei
- **Animations:** Framer Motion
- **Email:** EmailJS
- **Deployment:** Render
